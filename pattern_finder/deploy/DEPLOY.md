# Pattern Finder на сервере 24/7

Пока бот запущен на твоём компьютере, он работает только когда компьютер включён.
На сервере бот работает круглосуточно, и автоскан не пропускает ни одной закрытой свечи.

## 1. Сервер

Ubuntu 22.04 или 24.04.
- **Без нейросети-мозга** (бот понимает описания по словарю): 2 vCPU, 2–4 ГБ памяти, 20+ ГБ диска.
- **С мозгом Qwen2.5-3B** (`python setup_brain.py`): **4 vCPU, 8 ГБ памяти, 40+ ГБ диска** —
  модели нужно ≈3–4 ГБ памяти, ещё столько же — боту, графикам и автоскану.
  Видеокарта не нужна. На сервере ставь через `python setup_brain.py` (Linux — llama-cpp-python
  ставится без проблем) или Ollama: `curl -fsSL https://ollama.com/install.sh | sh`, затем
  `python setup_brain.py --ollama`.

⚠ **Важно: выбирай сервер в Европе или Азии, не в США.** Binance не отдаёт данные
серверам из США — бот не получит свечи.

После покупки у тебя будет IP-адрес сервера и пароль (или ключ) пользователя `root`.

## 2. Подключение

В Windows открой PowerShell:

```
ssh root@IP_СЕРВЕРА
```

Создай отдельного пользователя для бота (работать под root небезопасно):

```
adduser bot
usermod -aG sudo bot
su - bot
```

## 3. Код

```
git clone https://github.com/nomiseee69/candels.git
cd candels/pattern_finder
```

Если репозиторий приватный, git спросит логин и пароль: вместо пароля вставь
GitHub-токен (GitHub → Settings → Developer settings → Personal access tokens).

## 4. Установка

```
bash deploy/install.sh
nano .env
```

В `.env` впиши:

```
TELEGRAM_TOKEN=токен от BotFather
TELEGRAM_CHAT_ID=твой chat_id
```

Сохранить в nano: `Ctrl+O`, `Enter`, выйти: `Ctrl+X`.

## 5. Перенос твоих данных с компьютера

**Сначала останови бота на компьютере** (Ctrl+C) — чтобы база не менялась во время копирования.
Потом в PowerShell на компьютере, из папки `pattern_finder` (вместо IP — адрес сервера):

```
scp users.db bot@IP:~/candels/pattern_finder/
scp -r patterns bot@IP:~/candels/pattern_finder/
scp -r models bot@IP:~/candels/pattern_finder/
scp ai.json bot@IP:~/candels/pattern_finder/
```

- `users.db` — пользователи, их паттерны, оценки, подписки и оплаты;
- `patterns` — скриншоты-примеры;
- `models` и `ai.json` — обученные нейросети («глаз» и значимость). Модель Qwen (2 ГБ) копировать
  не обязательно — на сервере её проще поставить заново (ниже).

Нейросеть для понимания слов — на сервере, из папки `pattern_finder`:

```
.venv/bin/python setup_brain.py
```

## 6. Запуск

⚠ **Бот на компьютере должен быть остановлен** и больше не запускаться. Два бота с одним
токеном мешают друг другу — Telegram отдаёт сообщения то одному, то другому
(в логах будет ошибка 409 Conflict).

```
sudo systemctl restart pattern-finder
journalctl -u pattern-finder -f
```

В логах должно быть «Бот запущен (обновление N)».
Выйти из логов: `Ctrl+C` (бот продолжит работать). Проверка: напиши боту в Telegram.

## 7. Обновления

Закоммить и запушь новую версию с компьютера (`git push`), потом на сервере:

```
cd ~/candels/pattern_finder
bash deploy/update.sh
```

Скрипт скачает код, прогонит тесты и перезапустит бота.

## 8. Подписка и оплата

**Звёзды (⭐ Telegram Stars)** работают сразу, настраивать ничего не нужно. Месячная подписка
продлевается сама каждые 30 дней, годовая — разовый платёж. Баланс звёзд виден в настройках бота в Telegram;
вывод в деньги — через Fragment по правилам Telegram (не сразу после оплаты, а спустя несколько недель).

**ЮKassa (карта РФ / СБП):**
1. Зарегистрируйся в ЮKassa (yookassa.ru) как самозанятый или ИП и создай магазин.
2. В личном кабинете: «Интеграция → Ключи API» → скопируй shopId и секретный ключ.
3. Впиши в `.env`: `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, `YOOKASSA_RETURN_URL=https://t.me/имя_бота`.
4. Перезапусти бота — в «💎 Подписка» появятся кнопки «💳». Бот сам раз в минуту спрашивает
   ЮKassa об оплате, публичный адрес и webhook серверу не нужны.
⚠ Правило Telegram: цифровые товары в боте — только за звёзды. Оплата сторонней кассой —
риск, что Telegram скроет бота в мобильных приложениях. Убрать ключи ЮKassa из `.env` —
останутся только звёзды.
Если ЮKassa потребует передавать чеки (54-ФЗ) — скажи, добавим отправку чека.

**Админ:** напиши боту `/admin` — откроется панель с кнопками: «👥 Пользователи» (нажал на
человека → выдать Pro на 30/365 дней, забрать Pro, вернуть оплату звёздами), «📣 Рассылка»,
«💾 Копия базы». Команды тоже работают, вместо ID можно @username: `/grant @user 30`,
`/revoke @user`, `/user @user`, `/refund @user`. Об ошибках и оплатах бот пишет админу сам.

**База и копии:** всё хранится в `users.db` (старый `users.json` переезжает сам при первом
запуске и остаётся как `users.json.migrated`). Копия базы — раз в сутки в `backups/`, хранится 7 последних.
Скачать копию к себе: `scp bot@IP:~/candels/pattern_finder/backups/*.db .`

## Полезные команды

| Что | Команда |
| --- | --- |
| Статус бота | `sudo systemctl status pattern-finder` |
| Перезапуск | `sudo systemctl restart pattern-finder` |
| Остановить | `sudo systemctl stop pattern-finder` |
| Логи вживую | `journalctl -u pattern-finder -f` |
| Логи за час | `journalctl -u pattern-finder --since "1 hour ago"` |
