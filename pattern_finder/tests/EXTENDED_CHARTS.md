# Finder Candles — расширенная проверка графиков

Сравнивались локальные снимки `d64914a` и `8a9b3f5`. На этих данных новая версия чаще оставляет выдачу пустой. Для четырёх запросов предыдущая версия с включённой настройкой «только похожие» дала тот же порядок монет, те же находки и те же оценки сходства с точностью записи до четырёх знаков. Оснований приписывать улучшение алгоритму ранжирования по этому опыту нет.

## Поиск на фиксированных котировках

Для каждого эталона проверены три монеты по отдельности на H1 и D1 на срезах после 160, 200 и 240 свечей. Будущие свечи отсечены перед вызовом сканера. Каждый запуск ранжировал монеты только одного таймфрейма на одну дату. Использовались `run_scan`, сканеры и группировка проекта. Транспорт Telegram заменён записью результата. Персонализация выключена, FVG разрешены всех степеней значимости, фильтр силы выключен. В старой версии тип вводился явно, в новой эталон получен из ответа по фото.

|---|---:|---:|---:|
| Медвежий FVG | 4 / 7 | 1 / 1 | 1 / 1 |

| Симметричный треугольник | 1 / 5 | 0 карточек | 0 карточек |

Для FVG пригодность возвращённого участка проверялась независимо по его индексу: разрыв вниз между первой и третьей свечой, отсутствие последующего касания середины и свежесть либо близость к текущей цене. Это минимальный критерий структуры; визуальную похожесть он не оценивает. Условие выполнено хотя бы раз в **9 из 18** пар «монета × срез». Старая версия вернула подходящий участок в 4 из этих 9, новая — в 1 из 9. На первом месте старая версия дала подходящий FVG в 3 из 4 непустых выдач, новая — в единственной непустой из шести. Три пропущенные ранее возвращавшиеся находки имели сходство 0,3364, 0,3364 и 0,4439. Один участок BTC встречается на двух срезах. Сохранённая карточка ETH D1 получила 0,7201.

Для линейных фигур в таблице сравнивается подтип, возвращённый сканером. Независимой экспертной оценки порядка визуально наиболее похожих фигур здесь нет. Пустая выдача по треугольнику не подтверждает отсутствие симметричных треугольников на рынке.

## Приоритеты следующего этапа

1. **Разобрать потери на фильтре сходства.** На отдельном наборе разметить рыночные кандидаты до отсечения, включая противоположное направление и слабые визуальные аналоги. Сравнить число неверных направлений, пропуски, первое место и пустые выдачи. Повторное тестирование только на этих четырёх эталонах не позволит выбрать порог.
2. **Различать реальные свечи и линии.** Добавить исходные линейные графики и монохромные свечи с известным OHLC. Проверять число баров, вертикальные тени, регулярность центров и честность причины отказа. Регрессии для этой проверки — 41 ложная свеча на рисунке Ринка и шесть лишних на монохромном рендере.
3. **Проверить выбор участка для W/M и выбор ветки по линиям.** Размеченная W на AVAX отклонена, а дневная W BTC проходит. При наличии линий прямой маршрут пропускает обычную проверку формы; при отсутствии разметки проверяет форму на всём кадре. У проверенного флага восстановлены 73 из 73 свечей и три линии, а проверка флага вызывается при двух. Сравнить на независимых кадрах с полями до и после фигуры, флагштоком и третьей вспомогательной линией.
4. **Уточнять цель при нескольких видимых разметках.** Проверить случаи, где один кандидат прошёл порог, но на графике остались другие зоны. Отдельно разметить CHoCH с достаточной предысторией, боковики с ретестами и пересечение Order Block с Breaker Block. В текущем наборе правильное число свечей само по себе не спасло CHoCH и Range.
5. **Различать слабую структуру и плохое фото в объяснении отказа.** Для FVG меньше 0,5 ATR текущая просьба перерисовать зону не устраняет причину. Добавить примеры около границы и проверять объяснение, сохраняя самостоятельную проверку места и направления.

Для следующей оценки нужны новые, не просмотренные при этом исследовании рыночные периоды, независимые разметчики для блоков и структуры, оригинальные мобильные скриншоты и обратная ГиП. Здесь мобильный формат проверен рендером. Общую «точность бота» по этим данным вычислить нельзя.

## Повторение

Проверено на Windows с Python 3.13.1, OpenCV 5.0.0, NumPy 2.5.4, pandas 3.1.0, Matplotlib 3.11.2 и SciPy 1.18.1. Другая версия рендерера или шрифтов может менять пиксели.

1. В отдельном кэше разместить семь JSON и `rink-fig4.png` по URL из строк `source` реестра. Сверить SHA-256. Для Coinbase различия в сериализации ответа могут менять хеш: при расхождении считать вход изменившимся до проверки значений. В реестр не включены сами рыночные ряды или внешние картинки.
2. Экспортировать в отдельные каталоги `d64914a` и `8a9b3f5` файлы Python и `tests/samples` из подкаталога `pattern_finder` соответствующих Git-снимков. Использовать одно Python-окружение проекта. Третьим аргументом передавать каталог с `bot.py`; имя каталога входит в название результата.
3. Из текущей рабочей копии выполнить команды ниже, подставив свои пути. После подготовки кэша команды работают локально. `guided` воспроизводит отдельный парный экзамен с указанным типом; `recognize` получает только пиксели. Для FVG в поле `start_error_bars` записано смещение найденной первой свечи относительно размеченной по горизонтальной координате. В `ranking` сохранён порядок карточек каждого запроса, включая пустые списки.

```powershell
$cache = ".pytest_cache/chart-eval/final"
$old = ".pytest_cache/chart-eval/d64914a"
$new = ".pytest_cache/chart-eval/8a9b3f5"
.venv\Scripts\python.exe tests/extended_charts.py prepare $cache $new
.venv\Scripts\python.exe tests/extended_charts.py recognize $cache $new
foreach ($version in $old, $new) {
    .venv\Scripts\python.exe tests/extended_charts.py rank $cache $version
    .venv\Scripts\python.exe tests/extended_charts.py guided $cache $version
}
.venv\Scripts\python.exe tests/extended_charts.py export $cache $new --output tests/extended_charts_results.jsonl
```
