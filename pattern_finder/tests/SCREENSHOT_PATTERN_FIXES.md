# Привязка линий к фигурам на фото

База сравнения — `21f6cfb`. Проверялись варианты, которые возвращает
`screenshot_choices`: семейство, подтип, направление и отказ.

- W/M. В двух проверках на восстановленных свечах до изменения был отказ, после распознаются подтверждённые W и M. Та же разметка над боковиком даёт отказ. На `dark_avax_lines.png` результат остался прежним: извлечение находит 103 свечи и две нисходящие линии, которых недостаточно для привязки обеих сторон шеи W.
- Флаг. Для бычьего и медвежьего примеров, у которых верхняя линия продолжена влево, оценка привязки выросла с 0,50 до 1,00. При отсутствии флагштока предложение не появляется. Это проверка правила на подготовленных свечах.
- Все 12 сохранённых PNG из `tests/samples` дали одинаковые варианты и отказы до и после. Замороженный набор из 50 исторических скриншотов представлен в этой ветке реестром результатов. Известные 43/50 здесь не перемерялись.

## Новые отрицательные проверки

Оба кадра — публичный повтор одной записи Binance Futures TUT/USDT
на 9 августа 2026 года, точка воспроизведения 07:01 UTC. В обеих версиях
скриншоты получили отказ. Файлы сверены по SHA-256 из описания снимков.
[Происхождение и хеши](https://github.com/edgedepthhq/edgedepth-terminal/blob/master/assets/README.md#18-october-2026)

- На тепловой карте видны сделки по отдельным тикам, стакан и CVD. Свечной ряд с отмеченной фигурой отсутствует. [EdgeDepth, тепловая карта](https://github.com/edgedepthhq/edgedepth-terminal/blob/master/assets/oss-realtime-20261018.png)
- На минутном footprint-кадре мало свечей. Цветные таблицы показывают объём по ценам, справа профиль объёма, линии относятся к профилю и текущей цене. Целевого паттерна не размечено. [EdgeDepth, footprint](https://github.com/edgedepthhq/edgedepth-terminal/blob/master/assets/oss-footprint-20261018.png)

Эти две проверки покрывают отказ на разных представлениях одного рынка. Новых
надёжно размеченных положительных скриншотов для оценки прироста не было.

В эталоне JTO 50 отсчётов индивидуального контура. Исходное окно содержит 52 свечи. Эталон передаётся существующему сканеру, но рыночный детектор со своими условиями не вернул совпадение на том же восстановленном ряду. Поиск по другим монетам на этой выборке не измерялся.

На 50 сохранённых рыночных кадрах, сверенных по SHA-256, контроль остался 43/50. Пара уже распознанных границ треугольника или канала не используется как отдельная разметка шеи.

### Совместимость эталона размеченной ГиП и рыночного сканера

Для воспроизведения использован прежний JTO/USDT. Разметка ограничивает окно свечами с индексами 4–55 включительно из 67. Опоры шеи находятся на свечах 23 и 41. После фигуры остаются 11 свечей. Раньше при передаче в сканер пропадала шея, а окно должно было закончиться на одной из последних трёх свечей. На входе полного сканера действовал ещё один фильтр — минимум 120 свечей для любого запроса.

Проверка после разработки проводилась на трёх других опубликованных графиках. В классификатор передавался только файл изображения. Рыночный вход для проверки локализации получен из восстановленных OHLC. Для вызова полного сканера свечам присвоены последовательные временные метки поддерживаемого интервала 1h. Это проверка пути до карточки по порядку свечей. Биржевые свечи с оригинальными метками времени в этом опыте не использовались.

| Контрольный график | Основание | Результат |
|---|---|---|
| [AVNT/USDT](https://closedcandle.com/uploads/articles/head-and-shoulders-vs-double-top/example-3.webp) | Средняя вершина выше плеч, два минимума задают восходящую шею, после правого плеча видна свеча ниже шеи | ГиП распознана в обеих версиях. На собственном ряду пустая выдача сменилась карточкой со сходством 1,00 |
| [IOTA/USDT](https://closedcandle.com/uploads/articles/does-the-neckline-have-to-be-horizontal/example-1.webp) | Выраженная средняя вершина, две впадины на пологой восходящей шее. Компактные плечи | Эталон не создан |
| [PENGU/USDT](https://closedcandle.com/uploads/articles/how-long-does-a-double-top-take-to-confirm/example-1.webp) | Два пика и горизонтальная поддержка. Отрицательный контроль для ГиП | ГиП не предложена |

Для каждого из эталонов AVNT и JTO поиск по восстановленным свечам двух других положительных графиков и отрицательного PENGU вернул пустую выдачу до и после. Все три новых графика из одного источника и одного таймфрейма. Оценки экспертов для попарного визуального сходства отсутствуют.
